## 1. Sum of Digits

### Problem

Write a function to find the sum of all digits of a given number.

### Example

Input:

```

```

Output:

```
10
```

Explanation:

```
1 + 2 + 3 + 4 = 10
```

### Concepts Used

* Functions
* While Loop
* Modulus Operator (%)
* Integer Division (/)

## 5. Armstrong Number

### Problem

Check whether a number is an Armstrong Number.

An Armstrong Number is a number equal to the sum of the cubes of its digits (for 3-digit numbers).

### Example

Input:

```
153
```

Output:

```
True
```

Explanation:

```
1³ + 5³ + 3³ = 153
```

### Concepts Used

* Digit Extraction
* Powers
* Loops
* Functions

## 12. Automorphic Number

### Problem

Check whether a number is Automorphic.

An Automorphic Number is a number whose square ends with the number itself.

### Example

Input:

```
25
```

Output:

```
True
```

Explanation:

```
25² = 625
```

Since 625 ends with 25, it is Automorphic.

### Concepts Used

* Digit Counting
* Modulus Operator (%)
* Powers of 10
* Number Manipulation

## 13. Happy Number

### Problem

A Happy Number eventually reaches 1 when repeatedly replaced by the sum of the squares of its digits.

### Example

Input:

```

```

```

```

Output:

```
True
```

### Concepts Used

* Digit Extraction
* Loops
* Mathematical Patterns
* Cycle Detection
