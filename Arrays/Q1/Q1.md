# Largest Element in an Array - Java

## Problem Statement

Given an integer array, find and return the largest element present in the array.

---

## Approach 1: Linear Traversal (Optimal)

### Algorithm

1. Initialize `max` with the first element of the array.
2. Traverse the array from start to end.
3. Compare each element with `max`.
4. If the current element is greater, update `max`.
5. Return `max` after the traversal is complete.

### Code Logic

```java
int max = arr[0];

for (int i = 0; i < arr.length; i++) {
    max = Math.max(max, arr[i]);
}

return max;
```

### Example

Input:

```text
[2, 5, 1, 3, 0]
```

Process:

```text
max = 2
max = max(2,5) = 5
max = max(5,1) = 5
max = max(5,3) = 5
max = max(5,0) = 5
```

Output:

```text
5
```

### Time Complexity

**O(n)**

* Every element is visited exactly once.

### Space Complexity

**O(1)**

* No extra space is used except a single variable.

---

## Approach 2: Sorting

### Algorithm

1. Sort the array in ascending order using `Arrays.sort()`.
2. The largest element will be at the last index.
3. Return `arr[arr.length - 1]`.

### Code Logic

```java
Arrays.sort(arr);
return arr[arr.length - 1];
```

### Example

Input:

```text
[2, 5, 1, 3, 0]
```

After Sorting:

```text
[0, 1, 2, 3, 5]
```

Largest Element:

```text
arr[arr.length - 1] = 5
```

### Time Complexity

**O(n log n)**

* Sorting dominates the complexity.

### Space Complexity

**O(log n)**

* Due to Java's sorting implementation for primitive arrays.

---

## Comparison

| Approach         | Time Complexity | Space Complexity |
| ---------------- | --------------- | ---------------- |
| Linear Traversal | O(n)            | O(1)             |
| Sorting          | O(n log n)      | O(log n)         |

---

## Conclusion

The **Linear Traversal** approach is the preferred solution because:

* Faster than sorting.
* Does not modify the original array.
* Uses constant extra space.
* Works efficiently for both positive and negative numbers.

Hence, the optimal solution has:

**Time Complexity:** O(n)

**Space Complexity:** O(1)
